# Welcome to the ContextFlow Wiki

**ContextFlow** is a Windows-native AI voice dictation tool that types directly into every text field.

ContextFlow is built differently than typical voice dictation apps:
- **Universal Injection**: Types into browsers, VS Code, Slack, terminals, Win32 dialogs, etc.
- **Offline-First**: Runs entirely on your machine using `whisper.cpp` (unless you opt-in to a cloud provider).
- **Low Latency**: Sub-300ms latency from speech end to text-in-app.
- **AI-Native**: Automatically cleans up filler words and resolves spoken corrections (e.g., "meet at 2, actually 3" → "meet at 3").
